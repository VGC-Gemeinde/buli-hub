0 · Muss vor Launch: echte Bugs

Ergebnis-melden-Formular: Sticky-Bar überlappt Teamsheets

Die fixierte Leiste („Noch offen … / Ergebnis melden") liegt über den beiden pokepast-Eingabefeldern; die Überschrift „Teamsheets" fehlt komplett. Fix siehe Ergebnis melden.dc.html: Teamsheets als reguläre Sektion im Fluss, Inhalt bekommt 140px Bottom-Padding, Leiste ist position: sticky; bottom: 0 mit Blur-Hintergrund — nichts wird je verdeckt.

Deaktivierte Orange-Buttons wirken kaputt

„Anmeldung absenden" / „Ergebnis melden" disabled = ausgewaschenes Orange mit weißem Text (zu wenig Kontrast, sieht aktiv-aber-blass aus). Neu: disabled = neutraler Chip bg oklch(0.92 0.01 262), text oklch(0.6 0.02 262) — Orange ist ausschließlich klickbaren Buttons vorbehalten.

Anzeigename-Feld rendert leer

Im Anmeldeformular ist das disabled Anzeigename-Feld eine leere graue Box (Testdaten ohne displayName). Fallback anzeigen: Discord-Username, sonst „Discord-Nutzer" — nie leer.

2 · Brand-Entscheidungen (DESIGN.md aktualisieren)

Text auf Orange

Weiß, überall. Ersetzt die alte Regel „falinks-blue auf Orange" (DESIGN.md §1). Gilt für Buttons, aktive Tabs/Pills, Zähler-Chips. Bei Labels ≤ 12px: Schriftgewicht 600+, nie Regular.

Tick-Größen

S · 14×7 — neben Micro-Labels (12–13px uppercase): Statuszeilen, Kicker, Menüeinträge

M · 18×9 — neben Sektions-Überschriften (h2) und Panel-Titeln

L · 22×11 — neben Seiten-Überschriften (h1), Landing-Credit

Immer skewX(-18deg). Ersetzt die aktuell fünf verschiedenen Maße (16×8, 18×9, 22×11, 14×7, 20×9). Inaktiv/neutral: Tick in border-Farbe statt Orange.

Sektions-Header

Eine Komponente statt drei. Tick M + h2 condensed uppercase 24px, tracking 0.03em · border-bottom · padding-bottom 12px · Meta rechts 13px muted. Ersetzt StaffSectionHeader (26px/pb-14), SectionHeading (24px/pb-12) und SectionHead (20px/pb-10).

Seitentitel

Genau zwei Größen: 40px Standard (Anmeldung, Profil, Staff, Match) · 34px kompakt, wenn rechts Meta-Elemente sitzen (öffentliche Übersicht, „Deine Saison"). Ersetzt text-4xl / 38px / 28–34px / text-3xl.

Container

Drei Breiten: 640px schmal (Profil, Anmeldung, Spieler-Wartezustände) · 760px Lesen (Match, Legal) · 1040px breit (Dashboards, öffentliche Übersicht, Staff). Einheitlich px-24/32, py-48. Footer-Innenbreite folgt der Seite.

Micro-Labels

Uppercase-Labels: tracking 0.12em, 12–13px, weight 600 — überall. Einzige Ausnahme: Landing-Credit behält 0.16em. Ersetzt den Mix aus 0.1 / 0.12 / 0.14 / 0.16em.

Links

Zwei Stile: Inline = brand-blue, underline, offset 3px (Legal-Seiten: orange Links → blau ändern). Aktion = semibold brand-blue mit „→", hover underline („Zum Spieler-Dashboard →", „Ansehen →"). Nackte Textlinks wie „Divisionen" im Saison-Strip werden Outline-Buttons oder Aktions-Links.

Leere Zustände

Ein Muster: Karte (border, radius 12, padding 30/32) mit Tick M (orange = Handlung möglich, border-grau = nur Info) + condensed Titel 24px + Body 15px muted + optional eine Aktion. Referenz: Anmeldung.dc.html, Screens 1e. Ersetzt nackte Sätze (Anmeldung, Seeding-Sperre, Match-Gast) und den dashed-Border-Sonderfall.

3 · Header & Navigation

Staff-Link in den Header. Staff/Admins sehen neben „Spieler-Dashboard" einen zweiten Nav-Eintrag „Staff-Bereich" (mit Tick S). Aktueller Zustand: Auf /staff heißt der einzige Nav-Punkt „Spieler-Dashboard" — Staff wirkt auf der falschen Seite. Der Eintrag im Avatar-Menü bleibt zusätzlich.

Aktiver Zustand konsequent: aktive Seite semibold brand-blue, inaktive medium muted (Hover → blau). Auf Unterseiten (Match, Seeding) Breadcrumb wie bisher, aber überall mit demselben Trenner „/" in border-Farbe.

Öffentliche Übersicht: Eingeloggte Spieler sehen in der Saison auf „/" keinen Nav-Hinweis, wo sie sind — „Liga" als dritten Nav-Punkt aufnehmen (Gäste sehen nur Logo + Sign-in).

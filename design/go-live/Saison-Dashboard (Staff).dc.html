Kein separates /staff/saison: läuft die Saison, wird der Staff-Bereich selbst zum Dashboard (1a, leer: 1b). Das Dashboard ist eine Triage-Liste — nur was Handlung braucht: Überfälliges, offene Freewins, dann der Wochenüberblick. Freewins werden direkt aus der Liste bestätigt. Die Match-Seite bekommt eine Staff-Zone mit zustandsabhängigen Aktionen: offenes Match (1c), Freewin wartet (1d), Ergebnis gemeldet (1e), Dialog Freewin vergeben (1f). Der leere Disputes-Platzhalter entfällt — Sektionen ohne Inhalt zeigen wir nicht.

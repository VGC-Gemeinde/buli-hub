# Plans (legacy)

The plans of every feature built before the hub adopted GitHub Spec Kit on 2026-10-16. Since then,
features are specified in `specs/`, one directory per feature.

These plans stay where they are because code comments link to them and they remain the best record
of how the existing behavior came to be. Read them as history: nothing new is added, and a plan
whose content a later spec supersedes carries a backlink note at its top. Code and tests win over
a plan; a spec wins over a plan.
